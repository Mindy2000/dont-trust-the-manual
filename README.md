# 请不要相信说明书

**Don't Trust the Manual** — 一本不太可靠的说明书，四章十三页相互连接的纸上解谜冒险。

和纸片居民「条条」一起，观察、尝试，把遗失的物件、证词与记忆接回去，找到最后一页的出口。

**在线试玩：** https://mindy2000.github.io/dont-trust-the-manual/

## 作品特点

- 十三页连贯谜题：前页取得的物件与观察成为后页的条件，包含接触、文字移色、折尺、边界、配重、搭桥、光照、镜像、叠页、脚注、装订与规则核验。
- 复古实验说明书风格，原创纸片角色条条，配合折痕、墨迹、穿线、粒子及物件入册与带入下一页的动画。
- 手机竖屏优先；短屏提供固定主要操作与可展开对白，也支持桌面鼠标与键盘操作。
- 实验目录、可重玩关卡、持续保存的观察笔记、每关三层主动提示、音效开关与柔和动效模式。
- 原生 HTML、CSS、JavaScript，全部内容包含在单个 `index.html` 中，无需后端和外部资源，可离线游玩。

## 游玩与保存

点击在线链接即可开始。页面底部「保存游戏」可下载单一 HTML 文件，用现代浏览器打开即可离线游玩。

进度保存在当前浏览器与当前网址中，在线与本地文件的进度不会自动互通。本版十三页冒险使用独立进度，原四关试玩版的旧进度不会自动折算到新冒险。

遇到困难可主动打开「条条的便签」，依次查看观察、推理和完整解法。支持点选的拖放物件，也可先点物件再点目标完成同一操作。
