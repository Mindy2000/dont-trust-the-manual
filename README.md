# 请不要相信说明书

**Don't Trust the Manual** — 一本不太可靠的说明书，四场关于好奇心的小实验。

和被困在书里的纸片居民「条条」一起，观察、尝试，并找到规则之外的出口。

**在线试玩：** https://mindy2000.github.io/dont-trust-the-manual/

## 作品特点

- 四个逐步展开的交互谜题，包含触碰、文字、光线与空间探索。
- 复古实验手册风格，配合纸张、墨迹、机械与荧光动效。
- 手机竖屏优先，也支持桌面鼠标与键盘操作。
- 分层提示、可重读的秘密边注、音效开关与柔和动效模式。
- 原生 HTML、CSS、JavaScript，所有内容包含在单个 `index.html` 中，无需后端或额外安装。

## 本地游玩

下载 `index.html` 后用现代浏览器打开即可。游戏会在当前浏览器中保存进度；可从实验档案重新开始。

如果需要帮助，点击「条条的便签」。支持拖放的文字也可通过“先点选、再点目标”操作。
