# 请不要相信说明书

[中文](README.md) · [English](README_EN.md)

**Don't Trust the Manual** — 一本不太可靠的说明书，七章二十八页相互连接的纸上解谜冒险。

和纸片居民「条条」一起，观察、尝试，把遗失的物件、证词与记忆接回去，修复说明书，带着写给下一位读者的信驶向书外。

**在线试玩：** https://mindy2000.github.io/dont-trust-the-manual/

游戏目前以中文提供，英文文档不代表游戏内已支持英文切换。

## 作品特点

- 二十八页连贯谜题：前页取得的物件与观察成为后页的条件，包含接触、文字移色、折尺、边界、配重、搭桥、光照、镜像、叠页、脚注、装订、规则核验、绕障牵线、折船与纸船启航。
- 复古实验说明书风格，原创纸片角色条条，配合折痕、墨迹、穿线、粒子及物件入册与带入下一页的动画。
- 手机竖屏优先；短屏提供固定主要操作与可展开对白，也支持桌面鼠标与键盘操作。
- 七章实验目录、说明书探索图、六处可选纸边记忆、可重玩关卡、持续保存的观察笔记、每关三层主动提示、音效开关与柔和动效模式。
- 原生 HTML、CSS、JavaScript，全部内容包含在单个 `index.html` 中，无需后端和外部资源，可离线游玩。

## 游玩与保存

点击在线链接即可开始。页面底部「保存游戏」可下载单一 HTML 文件，用现代浏览器打开即可离线游玩。下载的是游戏程序，不包含当前进度存档。

进度保存在当前浏览器与当前网址中，在线与本地文件的进度不会自动互通。本版会兼容原十三关、二十四关及二十八关版本在同一浏览器、同一地址保存的进度；原四关试玩版的旧进度不会自动折算到新冒险。

遇到困难可主动打开「条条的便签」，依次查看观察、推理和完整解法。支持点选的拖放物件，也可先点物件再点目标完成同一操作。
