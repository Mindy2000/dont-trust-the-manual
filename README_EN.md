# Don't Trust the Manual

[中文](README.md) · [English](README_EN.md)

A slightly unreliable instruction manual: a paper puzzle adventure with **seven chapters and twenty-eight connected pages**.

Meet Tiaotiao (条条), a resident of this paper world. Observe, experiment, and reconnect missing objects, testimony, and memories to restore the manual and carry a letter to its next reader.

**[Play in your browser](https://mindy2000.github.io/dont-trust-the-manual/)**

The game currently uses **Chinese** for its story, puzzle text, and instructions. This English README does not add an English in-game language option.

## Features

- Twenty-eight connected puzzles: objects and observations from earlier pages become conditions for later ones. Mechanics include touch, moving printed color, measurement, boundaries, balance, bridges, light, mirrors, layered pages, footnotes, binding, checking rules, routing a thread around obstacles, folding a boat, and setting sail.
- A retro experimental-manual look, an original paper character, and animations with folds, ink, threads, particles, and objects carried into later pages.
- Designed primarily for portrait phones, with short-screen controls and expandable dialogue; desktop mouse and keyboard input are supported too.
- A seven-chapter index, an explorable book map, six optional paper-edge memories, replayable pages, persistent observation notes, three levels of optional hints per puzzle, sound controls, and reduced-motion mode.
- Plain HTML, CSS, and JavaScript in one self-contained `index.html`. No backend, build step, or external assets are required.

## Play online or offline

Open the online link to begin. To play locally, download or clone this repository and open `index.html` in a modern browser.

The in-game **保存游戏** button (“Save game”) downloads the self-contained HTML game for offline play. **It downloads the game program, not a portable progress save.**

Progress is stored in browser local storage for the current browser and URL. Online and local-file progress do not automatically transfer. Moving or renaming the file, changing browsers, or clearing site data may affect access to saved progress. Existing thirteen-, twenty-four-, and twenty-eight-page progress is retained in the same browser at the same URL. Progress from the original four-puzzle demo is not automatically converted into this adventure.

## Controls and hints

Observe the page and try its interactive objects. For objects with a click-selection alternative to dragging, select the object first, then select its destination.

If you are stuck, open **条条的便签** (“Tiaotiao’s notes”) for an observation, reasoning hint, and complete solution, revealed in that order. Sound and motion can be adjusted with the page controls.
